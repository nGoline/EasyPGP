ALPHA · UNAUDITED

Easy PGP is under active development and has not been security audited. Do not use it to protect anything whose disclosure would put you at risk. Your passphrase cannot be recovered — forget it and messages encrypted to that key are gone.

What it does

Messages

Encrypt to someone's public key and decrypt what they send back. Paste in, copy out.

Keys on device

Generate, import and manage key rings locally. Nothing is uploaded anywhere.

Hardware keys

YubiKey over USB and NFC, using the OpenPGP applet.

Sealed at rest

Private keys sit behind an Android Keystore key that needs your fingerprint or PIN.

Testing channel

Builds before they are released

Everything on this page is on Google Play already — install it there and updates arrive like any other app. The testing channel is separate: it gets each build a while before it reaches everyone, which is useful if you want to help find problems. You can leave it at any time and go back to the released version.

  1. Join the testers group

    groups.google.com/g/easygpg-testers — membership is what Play checks. Anyone can join; no approval needed. Use the Google account that is on your phone.

  2. Opt in

    On a computer, use the web opt-in page. On your phone, the option appears near the bottom of the store listing. Joining the group has to come first — Play checks it at this point, and membership can take a few minutes to register.

  3. Install as usual

    Play then offers you the test build instead of the released one. Leaving the group, or opting out, puts you back on the released version at the next update.

Useful feedback

What actually helps

Anything that goes wrong with keys, passphrases or hardware. Tell us the device, the Android version, and what you expected to happen — open an issue. Found a security flaw? Report it privately instead: see CONTRIBUTING.
